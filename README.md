strctr — набор шаблонов, скриптов для проектирования интерфейсов и логики на стороне сервера (framework).

Синтаксис автора может и будет отличаться от общепринятых стандартов программирования среди сообществ разработчиков, этот проект создан для самовыражения и приобритения навыков программирования.

Работа с фреймворком на уровне http запросов отталкивается от понимания устройства каталогов в операционной системе, способов сопоставления с пространством имен и методов обращения к файлам средствами http. Архитектура скриптов отражает SOLID подход, но без строго соблюдения всех принципов лежащих в основе проектирования данным способом.
